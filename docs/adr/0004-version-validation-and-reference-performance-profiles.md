# Version validation and reference performance profiles

GeoRBF owns a versioned validation profile that combines independent analytic and high-precision oracles, unit-aware canonical acceptance tolerances, proof-backed diagnostic corpora, and frozen reference performance workloads. Conditioning and backend status may add risk evidence or trigger retries but never relax semantic success, while wall-clock promises apply only to named representative profiles on a manifest-pinned dedicated runner; pathological inputs remain subject to correctness, diagnosis, and capacity guarantees rather than a latency SLA. This separation prevents production code from validating itself, keeps numerical meaning stable across backends and platforms, and makes performance regressions observable without turning incidental machine noise into domain semantics.
