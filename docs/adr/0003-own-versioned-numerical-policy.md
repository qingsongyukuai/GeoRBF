# Own a versioned numerical policy and verify recovered semantics

GeoRBF owns a versioned, reversible numerical policy above form-driven `faer` and Clarabel adapters so scaling, CPD reduction, rank evidence, retries, and diagnostic boundaries remain independent of backend defaults. Backend termination only yields evidence or a candidate; a solved model or problem diagnosis requires recovery and independent verification against the Canonical Problem IR in physical units, while backend versions and settings remain separately fingerprinted implementation details.
